# Contributing

Thanks for your interest in contributing to AgriAlert. Please follow these guidelines.

1. Fork the repository and create a topic branch.
2. Run the project's checks locally: `./gradlew lint assembleDebug`.
3. Add tests for new features and bug fixes.
4. Keep commits small and atomic; write clear commit messages.
5. Open a pull request with a description of changes and screenshots if UI changes.

Reviewers will check for style, tests, and CI passing.
